# C++ 基线测试（4 道代码题）

> 时间：45 分钟，闭卷（可查 cppreference 语法，不可查题解/教程）
> 目的：测「还记得多少、能在没有编辑器补全的情况下写对多少」，用于调 C 语言起步的强度，不打分排名。
> 编译：`g++ -std=c++17 -Wall -g 文件名.cpp -o 文件名`

## 规则

- 每题新建一个 `.cpp`，能编译、能跑出结果优先于「写得漂亮」
- 卡住超过 8 分钟就跳过，最后补；**不要留空**，写伪代码/注释也算分
- 不允许 `#include <bits/stdc++.h>`，用哪个头文件自己写

## 第 1 题 · 引用与指针（10 分）

写两个交换函数并各调用一次：

```cpp
void swapRef(int &a, int &b);
void swapPtr(int *a, int *b);
```

再用**指针**遍历一个 `int arr[5]`，求最大值和它的下标。

要求：main 里打印交换前后的值、最大值与下标。

## 第 2 题 · 内存与字符串（10 分）

实现：

```cpp
char *dupstr(const char *s);   // 用 new char[] 分配，复制内容（含 '\0'），返回指针
```

在 main 中调用、打印结果，最后正确释放。

要求：说明（注释即可）为什么用 `new char[]` 就必须用 `delete[]`，以及如果忘了 `delete[]` 会发生什么。

## 第 3 题 · 类与 RAII（10 分）

写一个 `IntArray` 类：

- 构造：接收长度 n，`new int[n]` 分配，初始化为 0
- 析构：释放内存，并打印 `"~IntArray(n)"`
- 提供 `int &at(int i)`
- **实现拷贝构造函数做深拷贝**（或显式 `= delete` 并说明理由）

main 中：创建 `IntArray a(3)`，给元素赋值，用 `a` 拷贝构造 `b`，打印两者内容，观察析构顺序。

## 第 4 题 · STL（10 分）

给定一段英文文本（自己写个字符串即可，含重复单词），用 `std::map<std::string, int>` 统计每个单词出现次数，按次数**降序**输出前 3 个；次数相同按字典序。

要求：处理标点和大小写（简化：只按空格切分、手动去逗号句号即可，不用正则）。
