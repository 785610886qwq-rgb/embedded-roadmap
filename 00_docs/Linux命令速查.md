# Linux 命令速查（持续追加）

> 规则：每条命令按「命令 / 作用 / 关键选项」记；踩过的坑记在最后一节，比命令本身更值钱。
> 提示符速认：`wyf@zhiyin:~$` = PS1，等命令；`>` = PS2，上一条命令没结束（续行或 heredoc）。

## 一、命令的基本结构

```
命令 [选项] [参数]
ls   -l      /mnt/d
```

- 选项：`-a` 短选项（可合并 `-lah`），`--version` 长选项
- 区分大小写：`ls` ≠ `LS`
- `Tab` 补全，`↑` 历史，`Ctrl+C` 中断，`Ctrl+D` 输入结束(EOF)，`Ctrl+L` 清屏

## 二、导航

| 命令 | 作用 | 备注 |
|---|---|---|
| `pwd` | 打印当前目录绝对路径 | print working directory |
| `cd 路径` | 切换目录 | `cd` 回家目录，`cd ..` 上一级，`cd -` 回上一个目录 |
| `ls` | 列目录 | `-a` 含隐藏文件，`-l` 长格式，`-h` 人类可读，`-d` 只看目录本身 |
| `ls -ld */` | 只列目录本身 | `*/` 匹配目录；不加 `-d` 会展开目录内容 |

## 三、文件与目录

| 命令 | 作用 | 备注 |
|---|---|---|
| `mkdir 名` | 建目录（不是文件） | `-p` 建多级、已存在不报错 |
| `rmdir 名` | 删空目录 | 非空目录用 `rm -r`（危险） |
| `touch 名` | 建空文件 / 更新时间戳 | |
| `cat 文件` | 显示文件内容 | 可接多个文件拼接显示 |
| `rm 文件` | 删文件 | `-f` 不存在也不报错；`rm -rf` 危险，慎用 |
| `cp 源 目标` | 复制 | `-r` 复制目录 |
| `mv 源 目标` | 移动/重命名 | 同目录内就是改名 |

## 四、重定向与管道

| 符号 | 含义 |
|---|---|
| `>` | 覆盖写入文件（不存在则创建） |
| `>>` | 追加到文件末尾 |
| `<` | 文件作为标准输入 |
| `<<` | heredoc，读到标记行为止（标记须顶格、一字不差、手敲） |
| `\|` | 管道：前一个命令的输出给后一个命令 |

## 五、编译与运行（本机 C）

| 命令 | 作用 |
|---|---|
| `gcc hello.c -o hello` | 编译；`-o` 指定输出名，不写默认 `a.out` |
| `./hello` | 运行当前目录的程序；`./` 不能省（当前目录不在 PATH） |
| `echo $?` | 上一条命令退出码：0 成功，非 0 失败 |
| `gcc -g -Wall x.c` | 带调试信息 + 开警告（写代码就加） |

## 六、帮助与历史

| 命令 | 作用 |
|---|---|
| `man ls` | 手册，`q` 退出，`/关键词` 搜索 |
| `ls --help` | 速查 |
| `history 5` | 最近 5 条命令 |
| `!141` / `!!` | 重跑第 141 条 / 上一条 |
| `Ctrl+R` | 反向搜索历史 |

## 七、踩坑记录（本机实测）

1. **花括号展开**：`{a,b,c}` 需 `bash` 且有逗号；被引号包住或单元素不展开。已实测出错案例：输入被拆成 `00_docs}` 等 9 个错误目录——入门期直接列名字：`mkdir -p 00_docs 01_notes ...`。
2. **heredoc 被 Windows CRLF 污染**：从网页复制 `EOF` 行会带 `\r`，导致永不结束。解决：结束标记手敲；或改用 `cat > 文件` + `Ctrl+D`。
3. **全角字符**：`$？`、`（`、`；` 在 shell 里无效。敲符号前切英文输入法。
4. **`>>` 不是 heredoc**：`>>` 是追加重定向，`<<` 才是 heredoc；`cat > f >> 'EOF'` 会建出名叫 `EOF` 的垃圾文件。
5. **路径**：`/mnt/d` = Windows D 盘；Windows 路径 `D:\x` 在 WSL 写 `/mnt/d/x`。
6. **DrvFs 权限**：`/mnt/d` 下文件显示 `rwxrwxrwx`，与 Linux 原生权限语义不同，属正常。
