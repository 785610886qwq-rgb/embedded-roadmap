## 2026-11-21 指针口试（4 题）

- ✅ 指针运算：`*(p+3)`、`p+3` 前进 12 字节（int 4 字节 ×3）
- ✅ 值传递 vs 指针传参：`f(&x)` 改得到，`f(int p)` 改不到
- ❌ `sizeof(s)`：数组 `char s[]="hello"` 是 **6**（含 '\0'），不是 1
- ❌ `int *p[3]` / `int (*p)[3]`：前者是指针数组（3 个 int*），后者是数组指针（指向 int[3]）
- 自评：指针「掌握得可以」，`sizeof`/`strlen` 区别记不清，二维数组指针需补

结论：指针可以提前进 W3 的内容，但 `sizeof` 与声明读法要先补。

## 已知差异（C++ → C 要改的习惯）

| 主题 | C++ | C |
|---|---|---|
| 输出 | `std::cout <<` | `printf("...", ...)` |
| 字符串 | `std::string` | `char[]` + `'\0'`，手写 strlen/strcpy |
| 内存 | `new` / `delete` | `malloc` / `free` |
| 引用 | `int&` | 没有引用，只有指针 `int*` |
| 函数 | 可重载、可默认参数 | 不能重载 |
| 结构体 | 可有成员函数、访问控制 | 只有数据成员，无方法 |
| 类型转换 | `static_cast<T>(x)` | `(T)x` |
| 布尔 | `bool` 内建 | C99 需 `#include <stdbool.h>` |
| 命名空间 | `namespace` | 无 |
