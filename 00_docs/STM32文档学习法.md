# STM32 文档学习法（文档为主，视频为辅）

> 适用：W11 起（2026-02 前后）。前置：C 语言 W3–W10 已过关（指针、结构体、位运算）。
> 原则：**以 ST 官方文档为主线；卡住时看别人怎么讲（视频/博客/论坛），看懂后回到文档确认。**

## 一、先分清四类文档

| 文档 | 编号/来源 | 用途 | 什么时候读 |
|---|---|---|---|
| 数据手册 Datasheet | DS5319（F103x8/xB） | 引脚定义、电气参数、封装、时钟上限 | 接线前查引脚，用时翻 |
| 参考手册 Reference Manual | **RM0008** | 每个外设的功能框图、寄存器、时序 | 主教材，按外设章节读 |
| 编程手册 | PM0056（Cortex-M3 内核） | NVIC、SysTick、异常模型 | 学中断/RTOS 前读 |
| 应用笔记 AN | AN2586（硬件设计）、AN4013（定时器）等 | 具体问题的官方解法 | 遇到问题再查 |

中文翻译件（只做辅助）：野火《STM32 HAL 库开发实战指南》、正点原子《STM32F1 开发指南》。它们贴 F103、例子多，但**寄存器描述以 RM0008 为准**，教程可能滞后。

## 二、每个外设的五步法（以 GPIO 为例）

1. **建最小工程**：CubeMX 选 F103C8T6，只开要用的外设，生成 Makefile 工程
2. **读 RM0008 对应章**：先看功能框图（数据流向），再看寄存器表（哪些位、什么含义），最后看时序图
3. **对照 HAL 源码**：`Drivers/STM32F1xx_HAL_Driver/Src/stm32f1xx_hal_gpio.c`，看它怎么写寄存器——HAL 就是把 RM 的表格翻译成 C
4. **自己写一遍**：不用 CubeMX 生成的初始化，手写寄存器版（`RCC->APB2ENR |= ...`），跑通
5. **用工具验证**：逻辑分析仪抓波形、万用表量电平、串口打印

> 验收标准（对应计划 M2）：不看教程、只查 RM 就能配 GPIO/UART/I2C/SPI/ADC/DMA。

## 三、阅读顺序（不要从第 1 页读）

1. RM0008 第 2 章「存储器与总线架构」——搞清地址空间、外设挂在哪条总线（APB1/APB2/AHB）
2. 第 7 章 RCC（时钟）——所有外设的前提，先会开时钟
3. GPIO → 外部中断 → 定时器 → 串口 USART → ADC → I2C → SPI → DMA
4. 每章只读三样：框图、寄存器表、时序图；例子代码看 HAL 例程

## 四、卡住时怎么办

文档读不懂是常态（比如时钟树、DMA 请求映射、时序图）。允许且鼓励：
- 看别人怎么讲：B 站/知乎/CSDN 的图解、野火正点的对应章节、ST 社区帖子
- 但**看完必须回到 RM0008 核对**：别人讲的是「他的理解」，寄存器行为以手册为准
- 视频只看卡住的那一段，不整集跟学；看懂后合上，自己从空工程写一遍

工具链、驱动、下载失败这类问题，官方文档覆盖少，直接看图文教程或短片段，优先 ST 社区（community.st.com）。

## 五、和江协套件的关系

套件可以买（硬件配套、接线一致），但**教程只当接线参考**，不当学习主线：
- 它的标准库例程可以用来对照「同一个外设，标准库怎么写、HAL 怎么写」
- 每课学完，关掉资料，从空工程自己写一遍——这才算学会
