# 板子第一课：认识板子，把「电脑 ↔ 下载器 ↔ 板子」打通

> 本课只做一件事：让 STM32CubeProgrammer 显示出 `64 KBytes`。
> 不写代码、不点灯、不装 CubeIDE。链路没通之前，写代码只会让你分不清是线的问题还是程序的问题。

## 0. 你要用到的东西

| 东西 | 数量 | 说明 |
|---|---|---|
| STM32F103C8T6 最小系统板（蓝板） | 1 | 主角 |
| ST-Link V2 下载器 | 1 | 电脑与板子之间的翻译 |
| Micro-USB **数据线** | 1 | 给板子供电，必须是数据线 |
| 母对母杜邦线 | 3 根 | 连接下载器和板子 |

## 1. 认识板子

![蓝板 SWD 四针位置](<D:/嵌入式学习/04_hardware/board-lesson1/bluepill-swd.jpg>)

看这张裁剪图的下半部分，从左到右四个针分别是：

| 丝印 | 含义 | 本课接不接 |
|---|---|---|
| `3V3` | 3.3V 电源 | 不接 |
| `34` | 芯片第 34 脚，功能是 `SWDIO` | 接 |
| `37` | 芯片第 37 脚，功能是 `SWCLK` | 接 |
| `GND` | 地 | 接 |

板子上其他东西本课不用管：`BOOT0`/`BOOT1` 跳帽（保持在 `0`）、`RESET` 按键、`PC13` 的 LED、USB 口。

## 2. 认识 ST-Link

ST-Link V2 有两种常见外观，先确认你是哪种：

**A. 蓝色铝壳/塑料小 U 盘，4 根针**（最常见）

针脚丝印通常是 `3.3V`、`SWDIO`、`SWCLK`、`GND`（有的印 `DIO`、`CLK`）。

**B. 白色塑料壳，20 针（2×10）**

![ST-Link 20 针引脚图](<D:/嵌入式学习/04_hardware/board-lesson1/stlink-pinout.jpg>)

图源：DirtyJTAG 文档 `docs/img/stlinkv2white-pinout.jpg`（MIT）。

20 针的板子上，SWD 信号不在最容易找的位置，**先拍照发我确认针脚定义，再接线**。以下接线按 A 型（4 针）写。

## 3. 安全：先看，再动手

- **防静电**：有手环就戴（另一端夹接地金属）；没有就先摸一下电脑机箱金属外壳。拿板子只捏边缘，手指别碰芯片引脚。
- **断电接线**：拔掉所有 USB 再插杜邦线。
- **不接 3.3V**：板子自己用 USB 供电，ST-Link 的 3.3V 不接，避免两个电源打架。
- **不热插拔**：上电后不要拔 SWD 线。
- **上电前检查**：有万用表就测 `3V3` 与 `GND` 之间电阻，不能是 0；没有表就目视检查有没有线搭在一起。

## 4. 第 1 步：接三根线

![ST-Link 与蓝板接线示意](<D:/嵌入式学习/04_hardware/board-lesson1/wiring.png>)

| ST-Link 针脚 | 板子针脚 | 颜色（示意） |
|---|---|---|
| `SWDIO` | `34`（`DIO`） | 蓝 |
| `SWCLK` | `37`（`CLK`） | 绿 |
| `GND` | `GND` | 黑 |
| `3.3V` | 不接 | 灰 |

**看哪里**：板子一端的四根针，丝印 `3V3 / 34 / 37 / GND`；ST-Link 那头丝印 `3.3V / SWDIO / SWCLK / GND`。
**做什么**：断电状态下，用三根母对母杜邦线按上表连接，插到底。
**正常现象**：三根线插紧、不松动；`3.3V` 那根悬空。
**如果不对**：

| 现象 | 原因 | 处理 |
|---|---|---|
| 找不到 `34`/`37` | 丝印在针脚旁，字很小 | 手机拍照放大看；或对照上面的裁剪图 |
| 杜邦线插不进 | 用了公对公线 | 换母对母（两头都是孔） |
| 线插上就掉 | 针脚歪了 | 用镊子轻轻扶正，别用蛮力 |

## 5. 第 2 步：上电，看电源灯

**看哪里**：板子 USB 口附近的电源 LED。
**做什么**：把 Micro-USB 数据线插到板子，另一头插电脑 USB 口。
**正常现象**：电源灯常亮（红色或蓝色，视板子而定）。
**如果不对**：

| 现象 | 原因 | 处理 |
|---|---|---|
| 灯不亮 | 用了充电线 | 换一根能传数据的线 |
| 灯不亮 | USB 口没电 | 换电脑上的 USB 口 |
| 灯闪一下就灭 | 板子短路 | 立刻拔掉，测 `3V3`-`GND`，拍照发我 |

## 6. 第 3 步：装 STM32CubeProgrammer

**看哪里**：ST 官网下载页。
**做什么**：打开 <https://www.st.com/en/development-tools/stm32cubeprog.html>，下载 Windows 版，一路 `Next` 安装（安装过程会装 ST-Link 驱动）。
**正常现象**：安装完成后，桌面/开始菜单出现 `STM32CubeProgrammer`。
**如果不对**：下载需要 ST 账号，注册一个即可；安装被拦截就右键「以管理员身份运行」。

## 7. 第 4 步：确认驱动

**看哪里**：`Win + X` → 设备管理器 → 展开「通用串行总线设备」或「端口 (COM 和 LPT)」。
**做什么**：插上 ST-Link 的 USB，观察列表变化。
**正常现象**：出现下面之一：

- `STM32 STLink`
- `STMicroelectronics STLink Virtual COM Port (COMx)`

**如果不对**：

| 现象 | 原因 | 处理 |
|---|---|---|
| 列表里没有 | 驱动没装 | 重装 CubeProgrammer，或额外装 STSW-LINK009 |
| 出现黄色感叹号 | 驱动异常 | 右键 → 卸载设备 → 重新插拔 |
| 出现「未知 USB 设备」 | 线或口问题 | 换线、换 USB 口 |

## 8. 第 5 步：连接，读出芯片

**看哪里**：CubeProgrammer 主界面。
**做什么**：

1. 左侧连接方式选 `ST-LINK`；
2. 点右上角 `Connect`；
3. 看右侧信息栏。

界面大致长这样（示意图，实际以软件为准）：

```
┌──────────────────────────────────────────────┐
│  ST-LINK ▼        Port: USB1      [ Connect ]│
│                                              │
│  Device:        STM32F103C8Tx                │
│  Flash size:    64 KBytes                    │
│  Device ID:     0x410                        │
└──────────────────────────────────────────────┘
```

**正常现象**：`Device` 显示 `STM32F103C8Tx`，`Flash size` 显示 `64 KBytes`。

**如果不对**：见下一节排错表。

## 9. 排错手册

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `No STM32 target found` | `GND` 没接 / 线接反 / 板子没供电 | 查三根线，确认板子电源灯亮 |
| `Cannot connect to target` | `BOOT0` 不是 0 / 芯片在低功耗 | 跳帽接 `0`，按 `RESET` 再连 |
| `ST-LINK USB communication error` | 充电线 / USB 口接触不良 | 换数据线、换口 |
| 连上但 `Flash size` 为 0 | 只接了信号线，芯片没供电 | 插板子 USB 供电 |
| `Device` 显示 `0x000` 或未知 | 芯片型号不符 / 假芯片 | 拍照发我，看丝印 |
| 反复掉线 | 杜邦线太长或接触不良 | 换短一点的线，插紧 |
